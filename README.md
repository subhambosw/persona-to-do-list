# Take Your Time // Persona 5 × Shin Godzilla Edition ⚡

A high-octane recreation of the **Persona 5** productivity task tracker inspired by [JigneshParmar24/Take-Your-Time](https://github.com/JigneshParmar24/Take-Your-Time), fully reimagined with the menacing **Shin Godzilla Atomic Blast** purple aesthetic, the iconic in-game **"DAYS UNTIL..."** mission deadline countdown, **Joker (The Persona Person)**, the **Original Godzilla Kaiju Roar**, the **Boredom Clear Dino Runner**, **Offline PWA** capability, and a full suite of **Persona RPG tactical features**!

---

## 💥 Features & Modules

### 1. 🎭 Persona Mascot (Joker / Ren Amamiya)
- **Official Character Background:** Authentic Persona 5 artwork of Joker looking back over his shoulder in his trenchcoat, bathed in Shin Godzilla atomic violet/purple hue.
- **Interactive Character Mascot:** Located at the bottom left with dynamic comic speech bubbles that react to your tasks and recent events.
- **Disguise Toggle:** Click Joker to switch between **Phantom Thief Joker** (mask) and **Shujin High Ren** (glasses).

### 2. 🦖 Authentic Godzilla Roar & Screen-Slicing Atomic Laser
- **Authentic Kaiju Roar:** Whenever you check off a task as completed, the authentic original Godzilla roar plays (`public/godzilla_roar.mp3`).
- **Screen-Slicing Atomic Laser Ray:** Completing any task automatically triggers a full-screen violet atomic blast laser cutting across the screen with screen shake and comic shockwave burst.
- **Atomic Energy Meter:** Visual gauge tracking radiation build-up from tasks and Pomodoro focus intervals.

### 3. 🕹️ Boredom Clear Minigame (Shin Godzilla Dino Runner)
- **Chrome Dino × Tomb of the Mask:** A high-speed retro runner minigame where you control Shin Godzilla (with animated running legs and pixel art styling).
- **Controls & Abilities:**
  - `SPACE` / `UP` / Click to jump over military tanks and obstacles.
  - `F` / Laser button to unleash the diagonal atomic ray against incoming airborne threats.
  - Score counter, high score tracker, HP bar, and Special beam energy meter.

### 4. ⏰ Scheduled Mission Reminders & Calling Card Takeover
- **Mission Timers:** Set custom reminder times or quick presets (`+15m`, `+1h`, `20:00`) for any mission objective.
- **Persona 5 Calling Card Alert:** When a reminder triggers, a full-screen dramatic Phantom Thieves Calling Card alert takes over the screen with options to Execute, Snooze (+5m), or Dismiss.
- **Offline PWA:** Complete offline functionality with service worker caching, local fonts, and Web App Manifest.

### 5. 🎯 Top-Right "DAYS UNTIL..." Calling Card (Priority Tracker)
- **On-Demand Appearance:** Appears in the top-right corner **only** when an active task is star-marked (`⭐`) and its deadline or reminder time is **near** (e.g. today or within 1–3 days).
- **Dynamic Stress Meter:** Automatically calculates days/hours remaining and outputs humorous anxiety warnings:
  - `DAYS 1-3`: *MAXIMUM PANIC! Heart Rate Climbing!*
  - `DAYS = 0`: *DO OR DIE! The Heist Commences!*
  - `OVERDUE`: *Expulsion! Mission Failed?*
- **Multi-Mission Support:** Cycle between multiple near starred missions with `★ 1/2` switcher buttons.

### 6. 📅 Persona 5 Calendar & Weekly Ribbon
- Classic Month/Day skewed quads, weather icon (Sun/Moon), and time-of-day indicator (Morning/Afternoon/Evening/Night).
- **Weekly Calendar Ribbon:** Click the day of the week button to open the horizontal 7-day ribbon.
- **Exit Back Button:** Dedicated **`EXIT CALENDAR [ESC]`** button, **`⮌ BACK`** ribbon button, click-outside backdrop, and keyboard `ESC` shortcut to exit back anytime.
- **`⮌ TODAY` Button:** Quick-return button appearing whenever navigating away from today's date.

### 7. ⚡ Tactical Bottom Command Dock & Lo-Fi Cassette Player
- **Bottom Ribbon Navigation:** Fast access to all tactical modules: `[LO-FI RADIO]`, `[INFILTRATE [25M]]`, `[CONFIDANTS]`, `[THIEF STATS]`, and `[5D STREAK ★]`.
- **Lo-Fi Cassette Deck:** Vintage Type-II stereo cassette player with **dual animated spinning tape spools**, track ticker, volume slider, and ambient weather sound FX.
- **Built-in Synthesizer Tracks:**
  - *Beneath the Mask* (Chill Rhodes chords & bass)
  - *Tokyo Daylight* (Upbeat jazz chords)
  - *Shin Godzilla Requiem* (Atmospheric atomic drone)
  - *Tokyo Rain Sound Generator* (Synthesized pink noise raindrops)

### 8. ⏳ Palace Infiltration Pomodoro Timer
- **High-Alert Countdown:**
  - **Palace Infiltration (25m Focus)**: Circular SVG progress ring with atomic radiation glow.
  - **Safe Room Respite (5m Short Rest)**
  - **Velvet Room Recovery (15m Long Regeneration)**
- **Security Alert Level:** Dynamic stealth gauge that reacts to consecutive infiltration sessions.
- **Rewards:** Grants **+25% Atomic Energy** per completed focus block.

### 9. 👥 Confidants & Social Links System
- **Tactical Companion Roster:**
  - **Morgana (I. The Magician)** — *Infiltration Maestro* (+20% bonus Atomic Energy per task).
  - **Ryuji Sakamoto (VII. The Chariot)** — *Punk Blitz* (High Priority tasks grant double EXP).
  - **Makoto Niijima (II. The Priestess)** — *Tactical Analysis* (Smart task priority clarity).
  - **Futaba Sakura (IX. The Hermit)** — *Position Hack* (Deadline proximity scanning & Pomodoro fatigue recovery).
  - **Ann Takamaki (VI. The Lovers)** — *Femme Fatale* (Charm booster & high-voltage neon styling).
- **Rank Up Ceremony:** Full-screen Tarot Arcana cut-in modal with ascending chime and perk unlocking.

### 10. 📊 5-Axis Phantom Thief Stats Pentagon Radar
- **Protagonist Radar:** 5-axis HTML5 Canvas radar chart evaluating:
  - **Knowledge** (Oblivious $\rightarrow$ Erudite)
  - **Guts** (Milquetoast $\rightarrow$ Lionhearted)
  - **Proficiency** (Bumbling $\rightarrow$ Transcendent)
  - **Kindness** (Inoffensive $\rightarrow$ Angelic)
  - **Charm** (Existent $\rightarrow$ Debonair)
- Interactive training actions and Rank S tier grading.

### 11. 🦖 Shin Godzilla Mutation & Evolution Streak
- **Mutation Roadmap:**
  - **Form 2: Kamata-Kun** (1+ Days) — *Crawling Primordial*
  - **Form 3: Shinagawa-Kun** (3+ Days) — *Thermodynamic Biped*
  - **Form 4: Kamakura Titan** (6+ Days) — *Phased-Array Radiation Spines*
  - **Form 5: Awakened Hybrid** (10+ Days) — *Tail-Spawn Annihilation*
- **Dorsal Atomic Beam:** Fires an intense violet radiation laser across the entire screen with camera tremors!

### 12. 💥 All-Out Attack Cinematic Finisher Screen
- **Victory Cut-in:** Automatically triggers when all daily missions are completed.
- Features dramatic comic diagonal slices, Joker + Shin Godzilla silhouette cut-in, victory fanfare, and the iconic finish quote:
  > **"THE PROCRASTINATION HAS BEEN EXECUTED."**

## 🚀 Running the App

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Open your browser at `http://localhost:3000`.
